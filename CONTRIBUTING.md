# Bijdragen

We gebruiken de "fork-and-pull" Git-workflow.

 1. **Fork** de repo op GitHub.
 2. **Clone** het project naar je eigen computer.
 3. **Commit** je wijzigingen in een eigen branch.
 4. **Push** je werk naar je fork.
 5. Open een **pull request**, dan bekijken wij je wijzigingen.

Let op:

- Haal eerst de laatste versie van "upstream" binnen voordat je een pull request opent.
- Draai `python build.py` en `python tools/check.py` voordat je een pull request opent. Als de controle faalt, wordt de pull request niet opgenomen.
- Gebruik geen externe resources: geen scripts, lettertypes, embeds of afbeeldingen van andere websites. Een gewone link naar een andere website mag wel.
- Afbeeldingen in `afbeeldingen/` mogen hooguit 300 kB zijn. Gebruik kleine letters en koppeltekens in bestandsnamen, geen spaties of haakjes. Geef elke foto een beschrijvende `alt`-tekst.
- Zet in uitrukken nooit persoonsgegevens, medische details of huisnummers.
